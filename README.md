## Name: media-cabinet ##
### Author: Alex Vu ###
### Date: 8/7/26 ###


## Description: ##
This is a media cabinet designed to track listening, watching, reading, and 
photo history on a month-by-month basis, all viwebale in an interactive 
3d-rendered space.

## Framework: ##
I use pyray, the python-specific version of raylib, a C-based graphics engine.
I wanted to use pyray for 2 reasons: better interaction with requests to get 
the data I want to show, and because I want to practice my python.
